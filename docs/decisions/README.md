# Architecture decision records

ADRs capture choices that materially constrain Fitara Work. Statuses are Proposed, Accepted, Superseded, Deprecated, or Deferred. Changing an accepted decision requires a new ADR that links to and supersedes the old one; do not silently rewrite historical rationale.
